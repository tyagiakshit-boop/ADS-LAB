# DSA Lab

A collection of programs, implementations, and solutions developed as part of the **Data Structures and Algorithms (DSA) Lab**.

This repository contains implementations of fundamental data structures and algorithms, along with practical lab exercises designed to strengthen problem-solving and algorithmic thinking.

## 📚 Topics Covered

The repository may include implementations and programs related to:

* Arrays
* Strings
* Linked Lists

  * Singly Linked List
  * Doubly Linked List
  * Circular Linked List
* Stacks
* Queues
* Circular Queues
* Recursion
* Searching

  * Linear Search
  * Binary Search
* Sorting

  * Bubble Sort
  * Selection Sort
  * Insertion Sort
  * Merge Sort
  * Quick Sort
* Trees

  * Binary Trees
  * Binary Search Trees
* Graphs

  * BFS
  * DFS
* Hashing
* Heaps
* Basic algorithm analysis
* Other problems covered during the DSA lab




## 🎯 Objectives

The main objectives of this lab are to:

* Understand fundamental data structures.
* Implement data structures from scratch.
* Learn and analyze common algorithms.
* Understand time and space complexity.
* Develop efficient problem-solving skills.
* Apply DSA concepts to practical programming problems.

## 🛠️ Languages & Tools

The programs in this repository are implemented using:

* **Programming Language:** C++ 
* **Editor/IDE:** VS Code or any preferred IDE
* **Version Control:** Git & GitHub

## 🚀 Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd DSA-Lab
```

Open the required program in your preferred IDE and compile/run it according to the programming language being used.

## 📊 Complexity Analysis

Where applicable, programs include analysis of:

* **Time Complexity**
* **Space Complexity**
* **Best, Average, and Worst Case Complexity**

Understanding complexity helps in choosing efficient solutions for different problems.

## 📝 Lab Work

Each directory contains programs corresponding to different DSA concepts and lab exercises. The implementations are intended for **learning, practice, and academic reference**.
